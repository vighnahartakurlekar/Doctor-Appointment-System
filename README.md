# Doctor Appointment System

A Java-based Doctor Appointment System developed to simplify the process of booking and managing appointments between patients and doctors. The application allows patients to register, log in, and book appointments, while doctors can view and manage their appointment schedules.

---

## Features

- 👨‍⚕️ Doctor Registration & Login
- 🧑 Patient Registration & Login
- 📅 Book Doctor Appointments
- 📋 View Appointment Details
- ❌ Cancel Appointments
- 🗂 Manage Patient Records
- 💾 Database Integration using MySQL
- 🖥 User-Friendly Interface

## Installation

### Prerequisites

- Java JDK 8 or above
- Eclipse IDE
- Apache Tomcat
- MySQL
- XAMPP (Optional)

### Steps

1. Clone the repository

```bash
git clone https://github.com/vighnahartakurlekar/Doctor-Appointment-System.git
```

2. Import the project into Eclipse.

3. Create the MySQL database.

4. Update database credentials in the JDBC connection file.

5. Start Apache Tomcat.

6. Open the application in your browser.
